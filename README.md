# OfflineNASViewer

A cross-platform file browsing application for local network file servers.

## Architecture

- **Backend** (Rust): REST API server for file system operations
- **Frontend** (React): Web interface for file browsing
- **Mobile** (Flutter): Mobile app for file browsing

## Quick Start

### Backend (Rust)
```bash
cd backend
cargo run
```

### Frontend (React)
```bash
cd frontend
npm install
npm start
```

### Mobile (Flutter)
```bash
cd mobile
flutter run
```

## Features

- Browse files and directories on a local network server
- Cross-platform support (Web, iOS, Android)
- REST API for file operations
- Real-time file system browsing
